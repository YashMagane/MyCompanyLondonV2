# 🌈 Advanced Figma to HTML & CSS Conversion

This project is a continuation of my previous Figma-to-code work, focusing on **refining visual design skills** using **HTML and CSS**.  
The goal was to recreate a different Figma design, applying more advanced styling techniques such as **gradient backgrounds**, **button design**, and **enhanced layout control**.

---

## 🧩 Project Overview

Building upon earlier projects, this task involved converting a brand-new **Figma design** into a functional and visually accurate multi-page website using **HTML5** and **CSS3**.  

The design included:
- **Home Page**
- **Services Page**
- **Contact Page**

Each page was carefully structured and styled to replicate the Figma reference as closely as possible.

---

## 🎨 Key Objectives

- Recreate the provided Figma layout with precision using HTML and CSS.  
- Incorporate **gradient color backgrounds** to enhance visual appeal.  
- Design and style **custom buttons** with hover effects and consistent spacing.  
- Maintain semantic, accessible HTML structure throughout all pages.  
- Strengthen understanding of CSS organization and component reusability.

---

## 🧰 Technologies Used

- **HTML** – for structure and semantics  
- **CSS** – for layout, color, and interaction design  

---

## 🎨 Design Highlights

- Implemented **linear and radial gradients** for modern backgrounds.  
- Created **custom buttons** using transitions and hover animations.  
- Ensured consistent color themes and typography.  
- Used **Flexbox** and **Grid** to align and space components effectively.  

---

## 💡 Learning Outcomes

- Improved understanding of **color gradients** and how to use them for modern web designs.  
- Learned to **design and style interactive buttons** with hover and focus effects.  
- Enhanced sense of **visual consistency** and **attention to design detail**.  
- Gained confidence in translating more complex Figma components into HTML and CSS.
